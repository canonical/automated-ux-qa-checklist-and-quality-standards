# Webpage template – character limits by section

Reference for automated copy doc reviews. Extracted from the official
Canonical webpage copy doc template (Google Doc).

Use these limits to flag content that exceeds the character count for its
section and element type. The `ch:` markers in copy docs map to these limits.

---

## Metadata

| Element | Max characters |
|---|---|
| Page title | 60 |
| Page description | 160 |
